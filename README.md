# THE LEE GROUP · Membrane Separations Lab (MSL)

전북대학교 유기소재섬유공학과 이영주 교수 연구실 홈페이지
주소: https://the-lee-group.github.io

## 내용 수정 방법
논문, 구성원, 소식, 모집 안내는 모두 `js/data.js` 파일 하나에 들어 있습니다.

1. 이 저장소에서 `js` 폴더 → `data.js` 클릭
2. 오른쪽 위 연필 아이콘(Edit) 클릭
3. 기존 항목 한 줄을 복사해서 내용만 바꾸기 (따옴표와 쉼표 유지)
4. 오른쪽 위 초록색 **Commit changes** 클릭
5. 1~2분 뒤 홈페이지에 반영

- 교수님 이름을 굵게: 저자 목록에서 `[Y. J. Lee]`처럼 대괄호로 감싸기
- 구성원 사진: `img` 폴더에 사진 업로드 후 해당 구성원의 `photo: "img/파일이름.jpg"`

## 파일 구성
- `index.html` 페이지 뼈대
- `css/style.css` 디자인
- `js/data.js` 내용 (주로 여기만 수정)
- `js/main.js` 화면 동작
- `img/` 사진
